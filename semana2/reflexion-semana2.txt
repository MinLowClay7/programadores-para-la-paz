Pregunta 9: ¿Por qué es importante para un desarrollador saber usar la terminal para navegar y organizar archivos dentro de un proyecto?
Respuesta: Hay 2 razones muy importantes para conocer esto, una de ellas es el uso de poder subir archivos al repositorio y que se guarden en un orden e entendimiento,
para verlo en GITHUB y la otra razón es para poder movernos por servidores, normalmente se presenta en la terminal lo cual el manejo de este es crucial.
